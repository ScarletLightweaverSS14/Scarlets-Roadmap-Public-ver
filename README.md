# Scarlet's Roadmap

This repository is a public roadmap for things I want to build, improve, revisit, and finish over time.

It exists to keep plans visible, show what I am actively working on, and keep a simple history of what has already been completed. It also helps me avoid spreading myself across too many projects at once.

## How this roadmap works

- New ideas and planned work can be added at any time.
- Priorities can change as projects evolve.
- Items can move between sections as work starts, pauses, finishes, or gets dropped.
- When something is done, it should be moved to **Completed** or clearly marked as finished so progress stays visible.
